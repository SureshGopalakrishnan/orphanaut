### Fixes in 2.2.1

- Route53: hosted zones with subdomain delegations or more than 300 records now delete instead of failing with "HostedZoneNotEmpty"
- Google Cloud: buckets with object versioning turned on can now be deleted
- New tests for every delete path on AWS, Azure and Google Cloud

### What's new in 2.2

- Tick resources with checkboxes, or use Select all
- New resource map that shows how each resource is connected
- AWS, Azure and Google Cloud logos
- Cleaner layout and shorter text

### Downloads

- Windows: `Orphanaut-Setup-Windows.exe` or `Orphanaut-Windows-Portable.zip`
- Mac (Apple Silicon): `Orphanaut-macOS-AppleSilicon.dmg`
- Mac (Intel): `Orphanaut-macOS-Intel.dmg`

If you're on 2.1.2 or later, the app will offer this update on its own.
